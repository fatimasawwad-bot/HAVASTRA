HAVASTRA | A World to Belong To
================================
An interactive, bilingual (English / Arabic) conceptual website for a university logo assignment.

HOW TO OPEN
Open index.html in Chrome, Edge, Firefox, or Safari. No installation is required.
The website uses external Unsplash reference photography and Google Fonts, so an internet connection is recommended.

FEATURES
- Cinematic coastal-village landing page
- Six destination pages via clickable cards and interactive map
- English/Arabic toggle and day/night mode
- Optional ocean-like ambient audio (off by default)
- Book shelf, bakery, cuisine, animal and planetary micro-interactions
- Identity, architecture reference gallery, mission and privacy considerations
- Responsive layout for phones and computers

NOTE
This is a fictional conceptual project. The architectural photographs are mood references and are not images of a built HAVASTRA development. The website includes a simplified owl mark that can be replaced with the original final assignment logo. The children's residential care area is not open to virtual public tours.

EDITING
Open index.html in a code editor. The 'worlds' JavaScript array controls the six destinations. 'photos' controls the image URLs, and 'tr' contains bilingual text.
